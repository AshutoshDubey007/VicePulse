Requests are counted per key and per day, and the counter resets at 00:00 UTC. Calls to this API and to the MadamNazar.io API are counted separately. Every answer tells you where you stand:
Response headers
Copy
RateLimit-Limit: 5

With 5 requests a day, a free key is for testing: ask for 25 entries per call and keep the answers. The data changes a few times a day at most.
Advertisement
Data 
model
A character, a car and a bar all have the same shape. Learn it once and every collection reads the same way, including the ones added after launch.
id
Stable and never reused, 
type.slug
. Store this one.
name, summary
Translated texts.
attributes
What is specific to the type: a vehicle’s class, a weapon’s real model. 
/types
 lists them.
relations
Typed links to other entries, with their name and address.
reliability
official
 (shown or named by Rockstar), 
press
 or 
community
. Leaks and rumours are never in the API.
verified_in_game
Turns 
true
 once we have checked the entry in the game, from November 19, 2026.
spoiler
Story content. Left out of lists unless you send 
spoilers=true
.
sources
The pages the entry comes from.
url
The entry’s page on vice-city.app, to link back to.
created_at, updated_at
Dates, to sync with 
/changes
.

API 
reference
All endpoints are 
GET
 and start with 
https://vice-city.app/api/v1
. Answers are JSON with a 
data
 field and a 
meta
 field. The Run buttons call the live API with the demo key.
Catalogue
GET
/{collection}
Free
List a collection.
 Returns the entries of one collection, sorted by name, with filters and paging.
lang
en | fr
One language as plain strings. Leave it out to get both.
limit
1–25 · 1–200
Page size. Up to 25 with a Free key, 200 with a Developer key.
cursor
string
Value of 
links.next_cursor
 from the previous page.
filter[…]
string
Keep entries matching a field, an attribute or a relation: 
filter[class]=sport
, 
filter[reliability]=official
, 
filter[region]=vice-city
. Repeat to combine.
q
string
Keep entries whose name or summary contains this text.
sort
name | updated_at | created_at
Prefix with 
-
 for descending order.
fields
list
Top-level fields to keep, comma-separated: 
fields=name,attributes
.

Cach
ing
The data only changes when we publish an update, so cache it. Every answer has an 
ETag
: send it back in 
If-None-Match
 and you get an empty 
304
 when nothing changed. 
meta.data_version
 changes with every update of the dataset.

A 304 still counts as a request. Check 
data_version
 with 
/game
, the lightest call, before refreshing a whole copy.

ors

). Branch on 
code
, which never changes, and show

, which says what to do. Give us 
instance
