Quick start

  1. Make a first call

    The vc_demo key needs no account. It returns the first 5 results of each list, which is enough to see the format.

    curl "https://vice-city.app/api/v1/characters?lang=en" \
  -H "x-api-key: vc_demo"
    const res = await fetch("https://vice-city.app/api/v1/characters?lang=en", {
  headers: { "x-api-key": "vc_demo" },
});
const { data, meta } = await res.json();
    import requests

res = requests.get(
    "https://vice-city.app/api/v1/characters?lang=en",
    headers={"x-api-key": "vc_demo"},
)
data = res.json()["data"]

  2. Get your own key

    Sign in to your MadamNazar.io account and open the Developer API section. Your key starts with mn_live_. vice-city.app is run by the same team, so the same key works on both APIs.

  3. Ask for what you need

    Filter, pick fields and choose a language in the URL. This returns the official sports cars, names only:

    curl "https://vice-city.app/api/v1/vehicles?filter[class]=sport&filter[reliability]=official&fields=name&lang=en" \
  -H "x-api-key: YOUR_KEY"
    const res = await fetch("https://vice-city.app/api/v1/vehicles?filter[class]=sport&filter[reliability]=official&fields=name&lang=en", {
  headers: { "x-api-key": "YOUR_KEY" },
});
const { data, meta } = await res.json();
    import requests

res = requests.get(
    "https://vice-city.app/api/v1/vehicles?filter[class]=sport&filter[reliability]=official&fields=name&lang=en",
    headers={"x-api-key": "YOUR_KEY"},
)
data = res.json()["data"]

Authentication

Send your key with every request, in the x-api-key header. Authorization: Bearer … works too.

Header
x-api-key: mn_live_xxxxxxxxxxxxxxxxxxxxxxxx

The API accepts calls from a browser (CORS is open), but a key in front-end code is visible to everyone. Call the API from your server, or cache the answers there.

Base URL : https://vice-city.app/api/v1

Data model

A character, a car and a bar all have the same shape. Learn it once and every collection reads the same way, including the ones added after launch.

id
Stable and never reused, type.slug. Store this one.
name, summary
Translated texts.
attributes
What is specific to the type: a vehicle’s class, a weapon’s real model. /types lists them.
relations
Typed links to other entries, with their name and address.
reliability
official (shown or named by Rockstar), press or community. Leaks and rumours are never in the API.
verified_in_game
Turns true once we have checked the entry in the game, from November 19, 2026.
spoiler
Story content. Left out of lists unless you send spoilers=true.
sources
The pages the entry comes from.
url
The entry’s page on vice-city.app, to link back to.
created_at, updated_at
Dates, to sync with /changes.

Declared and empty until the game is out, then filled from the game : /missions /collectibles /trophies /cheats.

Every translated text comes in English and French. By default you get both, which suits a bilingual app or a local copy:

    "fr": "Jason Duval"

API reference

All endpoints are GET and start with https://vice-city.app/api/v1. Answers are JSON with a data field and a meta field. The Run buttons call the live API with the demo key.

Catalogue

GET/{collection}

Free

List a collection. Returns the entries of one collection, sorted by name, with filters and paging.

langen | fr
One language as plain strings. Leave it out to get both.
limit1–25 · 1–200
Page size. Up to 25 with a Free key, 200 with a Developer key.
cursorstring
Value of links.next_cursor from the previous page.
filter[…]string
Keep entries matching a field, an attribute or a relation: filter[class]=sport, filter[reliability]=official, filter[region]=vice-city. Repeat to combine.
qstring
Keep entries whose name or summary contains this text.
sortname | updated_at | created_at
Prefix with - for descending order.
fieldslist

Caching

The data only changes when we publish an update, so cache it. Every answer has an ETag: send it back in If-None-Match and you get an empty 304 when nothing changed. meta.data_version changes with every update of the dataset.

curl
curl "https://vice-city.app/api/v1/weapons" \
  -H "x-api-key: YOUR_KEY" \
  -H 'If-None-Match: "ArBkgtbVqGOZaazeWq6yboZlsDE"'

A 304 still counts as a request. Check data_version with /game, the lightest call, before refreshing a whole copy.

Errors

Errors follow RFC 9457 (application/problem+json). Branch on code, which never changes, and show detail, which says what to do. Give us instance if you write about a problem.
